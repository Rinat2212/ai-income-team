# DatingGrowth AI — модуль продвижения Telegram-бота

Модуль для аккуратного продвижения Telegram-бота **@my_daivinchik_2212_bot** через открытые тематические сообщества.

## Принципы MVP
- Каталог сообществ добавляется вручную после проверки публичной ссылки и правил.
- Агент готовит персонализированные черновики предложений администраторам.
- Любой исходящий текст требует ручного одобрения владельца.
- Нет автоматических массовых личных сообщений, обхода ограничений Telegram или публикаций без разрешения администратора.
- SQLite хранит каталог, черновики, статусы и события переходов.
- DRY_RUN=true включён по умолчанию; MVP не публикует сообщения в группы.

## Запуск
1. Установите Python 3.11+.
2. Создайте Telegram-бота через BotFather и получите токен.
3. Скопируйте .env.example в .env, заполните BOT_TOKEN и свой числовой ADMIN_ID.
4. Установите зависимости: pip install -r projects/datinggrowth/requirements.txt.
5. Запустите из корня репозитория: python -m projects.datinggrowth.bot.

## Команды администратора
- /start — проверка доступа и инструкция.
- /addcommunity Название | https://t.me/... | правила/контакт — добавить проверенное открытое сообщество.
- /communities — список каталога.
- /draft ID сообщества | текст — создать черновик предложения.
- /queue — показать ожидающие решения черновики.
- /stats — сводка по сообществам, черновикам и отслеженным переходам.

Кнопки «Одобрить» и «Отклонить» меняют статус черновика. Одобрение разрешает использовать текст вручную, но не отправляет его автоматически.

## Аналитика
Бот может считать переходы на deep-link-коды вида https://t.me/<имя_этого_бота>?start=src_<код>. Это измеряет открытие служебного бота, а не запуск целевого @my_daivinchik_2212_bot. Для достоверной атрибуции целевой бот должен сам обрабатывать start payload.
