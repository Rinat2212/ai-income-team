# AI Income Team

Бесплатная модульная система ИИ-агентов для исследования возможностей заработка, подготовки материалов и автоматизации рутинных задач.

## Текущий этап

- Python-ядро и координатор задач.
- 11 зарегистрированных логических агентов.
- Безопасный режим `DRY_RUN`.
- Базовые unit-тесты.
- GitHub Actions для проверки синтаксиса и тестового запуска.

## Файлы

- `config.py` — настройки проекта и список агентов.
- `core/coordinator.py` — базовый координатор задач.
- `main.py` — точка входа и отчёт о состоянии.
- `tests/test_core.py` — тесты координатора.
- `.github/workflows/tests.yml` — автоматические проверки GitHub Actions.

## Запуск

Требуется Python 3.12 или совместимая версия.

    python main.py

## Проверка

    python -m compileall -q config.py main.py core tests
    python -m unittest discover -s tests -v

## Безопасность и ограничения

На начальном этапе внешние действия отключены: система не публикует материалы, не рассылает сообщения и не выполняет платежи. Прогнозы и найденные возможности не считаются полученным доходом. Платные API не используются.
